### ⚡ Quick Ping

Saya suka mengulik titik temu antara **keandalan infrastruktur** dan **arsitektur backend**. Sebagian besar waktu saya dihabiskan di terminal: memetakan topologi jaringan, mengisolasi container di cluster Proxmox, mendesain pipeline automasi, atau mencari tahu kenapa ada paket jaringan yang drop di tengah malam.

Bagi saya, sistem terbaik adalah sistem yang bekerja senyap di latar belakang—tahan banting, scalable, dan terdokumentasi dengan baik.

* 🛠️ **Fokus Utama:** Bare-metal virtualization, network isolation, honeypot security analysis, & REST API backends.
* ☕ **Bahan Bakar:** Shell scripting, log monitoring di Grafana, dan teh hangat larut malam.
* 🎯 **Misi Saat Ini:** Mendalami implementasi Terraform/Ansible untuk *Infrastructure as Code* (IaC) dan orkestrasi Kubernetes.
