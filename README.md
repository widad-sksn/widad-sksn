## 📌 Executive Summary

Infrastructure Engineer and Backend Developer specializing in production server orchestration, virtualization clusters, enterprise routing, and scalable backend services.

- 🐧 **Linux & Virtualization**: Proxmox VE high-availability clustering, Docker containerization, system hardening, and automated disaster-recovery.
- 🌐 **Network Engineering**: Enterprise MikroTik RouterOS management, VLAN segmentation, firewall policies, WireGuard/IPsec tunnels, and FTTH infrastructure.
- ⚡ **Backend Development**: High-performance REST APIs and microservices using PHP (Laravel) and Python, paired with optimized MySQL and PostgreSQL databases.
- 🤖 **Automation & Reliability**: CI/CD pipelines, Bash scripting for administrative tasks, and zero-downtime deployment workflows.
